III. Windows Server - Ismeretanyag

Active Directory és Tartományok

A Munkacsoport (Workgroup) decentralizált, míg a Tartomány (Domain) központilag menedzselt. Az Active Directory (AD) teljes mértékben a DNS-re (Domain Name System) támaszkodik, anélkül nem működik.

  • SYSVOL mappa: A csoportházirendek (GPO) és a bejelentkezési szkriptek (logon scripts) tárolására szolgál a Domain Controlleren.
  • Fiók letiltása (Disable): A fiók adatai megmaradnak, de a felhasználó nem tud bejelentkezni.

GPO (Group Policy Object)

A Csoportházirend célja a felhasználók és számítógépek beállításainak központi kezelése. Ezzel tiltható le például a Vezérlőpult, vagy állítható be a háttérkép minden gépen.

PowerShell és Parancsok

  • Új AD felhasználó létrehozása: New-ADUser
  • Futó szolgáltatások listázása: Get-Service
  • Futó folyamatok: tasklist
  • Fájlrendszer ellenőrzése: sfc /scannow
  • Leállítás azonnal: shutdown /s /t 0

Fontos Windows Szolgáltatások

  • WSUS: Windows Server Update Services - Frissítések központi terjesztése a hálózaton.
  • WDS: Windows Deployment Services - Felügyelet nélküli (hálózati) operációs rendszer telepítésekhez.
  • IIS: Internet Information Services - Windows Server webszerver szerepköre.
  • Hyper-V: A Microsoft beépített virtualizációs technológiája.
  • RDP: Remote Desktop Protocol - Távoli asztali elérés.
  • Windows Server Core: Csak parancssoros felület, kevesebb erőforrást használ és kisebb a támadási felülete.
  • Failover Clustering: Nagy rendelkezésre állás (HA) biztosítása szerverek között.

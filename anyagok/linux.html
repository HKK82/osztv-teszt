III. Linux - Ismeretanyag

Fájlrendszer és Jogosultságok

A Linux fájlrendszer hierarchikus. Fontosabb könyvtárak:

  • /etc: Rendszerszintű konfigurációs fájlok.
  • /home: Felhasználók saját könyvtárai.

Fontos fájlok:

  • /etc/passwd: Felhasználói fiókok alapadatai.
  • /etc/shadow: Felhasználói jelszavak titkosítva tárolva.
  • ~/.bashrc: Felhasználó saját környezeti változói és beállításai belépéskor.

Jogosultságok: chmod 755 jelentése: a Tulajdonos olvas, ír, futtat (7), a Csoport és Mások csak olvasnak és futtatnak (5).

Alapvető Parancsok

  • pwd: Aktuális könyvtár elérése (Print Working Directory).
  • ls: Könyvtár tartalmának listázása.
  • rm: Fájl törlése.
  • cp: Fájl másolása.
  • less: Fájl tartalmának megjelenítése oldalanként.
  • df: Szabad és foglalt lemezterület.
  • free: Memóriahasználat megjelenítése.
  • ps: Aktív folyamatok megjelenítése.
  • kill [PID]: Folyamat leállítása szignállal.
  • sudo: Root (admin) jogosultság kérése egy parancshoz.

Szolgáltatások és Hálózat

  • systemctl enable: Szolgáltatás automatikus indítása rendszerindításkor.
  • crontab -l: Ütemezett cron feladatok listázása.
  • apt update és apt upgrade: Csomagok frissítése Debian/Ubuntu rendszereken.
  • ip addr: Hálózati interfészek és IP címek listázása.
  • ufw enable: UFW (Uncomplicated Firewall) bekapcsolása. (Tiltás: ufw deny 80/tcp)
  • ssh-copy-id: SSH publikus kulcs másolása a távoli szerverre (jelszó nélküli belépéshez).
  • Swap: A RAM kiegészítése lemezterülettel, amikor elfogy a fizikai memória.
